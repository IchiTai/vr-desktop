どちらの機器で開いていますか?

パソコン側で共有をはじめてから、見る側の機器でコードを入力します。

映像は機器の間で直接やり取りされ、外部のサーバーには保存されません。詳しくは使い方ガイドへ。
PC / Mac

画面を共有する

ボタンを押すと、どの画面を共有するか選ぶウィンドウが開きます。

  1. 「画面全体」を選ぶ(VRからの操作が正しく動きます)
  2. 音も聞きたいときは「音声を共有」にチェック
  3. 「共有」を押す

操作モード OFF(見るだけ)
VRやスマホからマウスを動かしたいときは、操作ヘルパーをこのパソコンで起動しておきます。
Windows: helper-windows.bat / Mac: helper-mac.py
はじめての起動手順は使い方ガイドにあります。起動すると、この欄が自動でONに変わります。

Quest / Phone / Tablet

コードを入力して接続する

パソコンの画面に表示されている6桁のコードを入力してください。

パソコンの画面を受信しています。

音はミュートで開始しました。映像を一度タップすると音が出ます。

VRの中での操作(標準設定)

右手 レーザー当てた画面のカーソルを動かす(操作モードON時)
右手 トリガー / グリップ左クリック / 右クリック
右手 スティック上下スクロール
左手 スティック上下で画面全体の遠近、左右で大きさ
左手 X / Y平面と湾曲の切替 / 画面を正面に呼び直す
左手 トリガー操作ガイドの表示切替

ボタンの割り当ては「⚙ 設定 → 操作」で変えられます。

操作モード OFF(見るだけ)

設定

同じボタンを選ぶと、前の機能と自動で入れ替わります。VRの中の操作ガイドにも、いまの割り当てが表示されます。

見る側で変えると、共有中のパソコンにもすぐ反映されます。文字がにじむときは「くっきり」、動画がカクつくときは「なめらか」を試してください。

VRの背景

背景は次にVRへ入るときに反映されます(パススルーは対応している機器のみ)。設定はこの端末のブラウザに保存されます。
