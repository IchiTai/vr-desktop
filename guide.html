🥽VR Desktop
使い方ガイド

これは何?

VR Desktopは、WindowsやMacの画面をMeta Quest 3の大画面で見て、そのままVRの中から操作するための自分専用ページです。パソコンにもQuestにも、アプリのインストールは必要ありません。パソコンはブラウザで画面を共有し、QuestはQuest本体のブラウザ(Meta Quest Browser)で受け取ります。スマホやタブレットも「見る側」として使えて、タッチでそのまま操作できます(画面の共有そのものはパソコン専用です)。

用意するものは、Chromeが入ったパソコン(Edgeでも動きます。Safariは対象外です)、Meta Quest 3、そして両方のインターネット接続です。文字を打つときは、パソコンの前のキーボードをそのまま使います。

1. 準備(最初の1回だけ)

このページ一式をインターネットに公開すると、パソコンとQuestの両方から同じURLで開けるようになります。画面共有とVR表示は、ブラウザの決まりで「https://」で始まるURLでしか動きません。ファイルをダブルクリックして開くだけでは使えないのは、このためです。

手元にあるのは次の4つのファイルです。まず、パソコンに「vr-desktop」という名前の新しいフォルダを作り、4つ全部をその中に入れてください。

  • index.html:本体のページ
  • guide.html:このガイド
  • helper-windows.bat:Windows用の操作ヘルパー
  • helper-mac.py:Mac用の操作ヘルパー

公開には、フォルダを置くだけで使える無料サービスを利用します。どれか1つを選んでください。中身の動きは、どれを選んでも同じです。

サービス手間向き不向き
Netlifyフォルダをドラッグするだけいちばん簡単。まず試すならこれ
Cloudflare Pagesドラッグ+最初の設定が少し通信量の制限がなく、動画のやり取りが多い使い方に安心
GitHub Pages最初だけ手順が10ステップ一度作れば更新も簡単。ずっと同じURLで使える

迷ったらNetlifyで始めてください。あとから乗り換えても、フォルダをドラッグし直すだけです。

選択肢A: Netlifyで公開する

  1. パソコンのブラウザで https://app.netlify.com/drop を開く
  2. 無料アカウントを作る(メールアドレスがあれば作れます。登録せずに公開すると1時間ほどで消えます)
  3. 「vr-desktop」フォルダを、ページの点線の枠へドラッグする
  4. しばらく待つと「https://〇〇〇.netlify.app」のようなURLが表示される。これがあなた専用のURLです
  5. そのURLを、パソコンとQuestの両方のブラウザでブックマークしておく

ファイルを作り直したときは、Netlifyのサイト画面にある「Deploys」にフォルダをもう一度ドラッグすると、同じURLのまま中身が入れ替わります。

選択肢B: Cloudflare Pagesで公開する

  1. パソコンのブラウザで https://pages.cloudflare.com/ を開き、無料アカウントを作る
  2. 管理画面で「Pages」を選び、「Upload assets」(ファイルを直接アップロードする方)を選ぶ
  3. プロジェクト名を決める(vr-desktop など。この名前がURLになります)
  4. 「vr-desktop」フォルダをドラッグして、デプロイを実行する
  5. 「https://vr-desktop.pages.dev」のようなURLが発行される。これをパソコンとQuestの両方でブックマークする

更新するときは、同じプロジェクトの「Create new deployment」からフォルダをドラッグし直します。

選択肢C: GitHub Pagesで公開する

GitHubの操作はすべてブラウザだけで完結します。専用ソフトのインストールは必要ありません。

  1. https://github.com/ で無料アカウントを作る
  2. 右上の「+」から「New repository」を選ぶ
  3. 「Repository name」に vr-desktop と入れ、「Public」のまま「Create repository」を押す
  4. 次の画面にある「uploading an existing file」のリンクを押す
  5. 4つのファイルをまとめてドラッグする(フォルダごとではなく、中の4ファイルを選んでドラッグします)
  6. 下の「Commit changes」を押す
  7. 上の「Settings」タブ → 左の「Pages」を開く
  8. 「Source」を「Deploy from a branch」にして、「Branch」で main と /(root) を選び、「Save」を押す
  9. 1〜3分待ってからページを再読み込みすると、上部に https://ユーザー名.github.io/vr-desktop/ というURLが表示される
  10. そのURLを、パソコンとQuestの両方のブラウザでブックマークしておく

ファイルを更新するときは、リポジトリの画面で「Add file」→「Upload files」から同じ名前のファイルをドラッグし、「Commit changes」を押します。反映まで1〜2分かかります。表示が古いままのときは、ブラウザで再読み込みしてください。

無料のGitHub Pagesでは、リポジトリを「Public」にする必要があります。ファイルの中身は誰でも見られる状態になりますが、この4ファイルにはパスワードも個人情報も入っていません。URLを知られても、6桁の接続コードがなければ画面には接続できません。
どのサービスでも、最初に開くファイルの名前は index.html である必要があります。中身は4つのファイルだけにして、フォルダの階層を作らないでください。

2. 毎日の使い方

パソコン側

  1. ブックマークしたURLをChromeで開き、「パソコン(共有する側)」を選ぶ
  2. 「画面の共有をはじめる」を押す
  3. 選択画面で「画面全体」を選ぶ。音も聞きたいときは「音声を共有」にチェックを入れて、「共有」を押す
  4. 6桁の接続コードが表示される

Quest側

  1. Questをかぶり、ブラウザ(Meta Quest Browser)でブックマークした同じURLを開く
  2. 「Quest(見る側)」を選び、パソコンに表示されている6桁のコードを入力して「接続する」を押す
  3. 映像が届いたら「VRで見る」を押す。目の前に大画面が現れます

やめるときは、Questはコントローラーのメニューボタンでブラウザに戻り、パソコンは「共有をすべてやめる」を押します(ブラウザ上部の「共有を停止」でもかまいません)。

画面を横に増やしたいとき(同じパソコンの別モニターや、もう1台のパソコン)は、「5. 複数の画面と複数のパソコン」を見てください。

スマホやタブレットで見るときの手順は、セクション6にあります。

3. VRの中での操作

VRに入った直後は、操作の一覧が画面の下にしばらく表示されます。左手のトリガーで、いつでも出し直せます。

操作はたらき
レーザー(両手に出ます)当てた画面のマウスカーソルを動かす(操作モードがONのとき)
トリガー(左右) / 右Aボタン(下)クリック。すぐ動かすとドラッグ、長押ししてから動かすとスクロール
右手 Bボタン(上)右クリック
グリップ(左右どちらでも)レーザーで指した画面をつかんで、好きな場所・高さへ移動(設定・操作一覧のパネルもつかめます)
右手 スティック上下スクロール。左右に倒すと横スクロール(ヘルパー版3から)
左手 スティック上下指した画面を遠くへ/近くへ
左手 スティック左右指した画面を大きく/小さく
左スティック押し込みポインター(レーザー)の表示/非表示
右スティック押し込みキー送信パレットを開く/閉じる
左手 Xボタン(下)設定メニューを開く/閉じる(画質・背景・最大距離など)
左手 Yボタン(上)画面の並びをいまの正面に呼び直す(「固定」した画面は動きません)
何もない所をクリック操作一覧の表示/非表示
操作一覧パネルをクリック設定メニューを開く(ボタンがわからなくなったときの保険)

トリガーは押し方で3通りに使い分けます。短く押すとクリック、押してすぐ動かすとドラッグ(テキスト選択やつまみの操作)、0.3秒ほど長押ししてから動かすとページをつかんだようにスクロールします。スクロール中はカーソルが動かないので、読み物を送るのに向いています。この動作は「⚙ 設定 → 操作」の「トリガーのドラッグ」で、常にドラッグする標準方式にも戻せます。

右スティックを押し込むとキー送信パレットが開きます。Enter・Esc・矢印・コピー/貼り付け・切り取り・取り消し・全選択・ウィンドウ切替・戻る/進むを、レーザーとトリガーでパソコンへ送れます。送信先は「最後にレーザーを当てたパソコン」で、パレットの上部に表示されます。パレット自体もグリップでつかんで好きな位置に置けます(新しいヘルパーが必要です)。

ハンドトラッキングにも対応しています(実験的)。コントローラーを置いて手をかざすと指さしの向きにレーザーが出て、親指と人差し指でつまむ(ピンチ)とクリックです。押し方の使い分けも同じで、つまんですぐ動かせばドラッグ、つまんだまま少し止めてから動かせばスクロールになります。画面の移動や大きさの調整はコントローラーで行ってください。

BluetoothキーボードをQuestにペアリングしていれば、VR中の打鍵がそのままパソコンに入力されます(最新のヘルパーが必要)。英数字・記号・矢印・Ctrl/Cmd系のショートカットに対応します。日本語の変換入力はスマホの「⌨」の入力欄が確実です。

VRの設定メニュー(左X)には「PC追加」ボタンがあり、テンキーで6桁コードを入力してVRの中から接続・再接続できます。「整列」ボタンはYボタンと同じ呼び直しです。メニュー下部の休憩リマインダー(30/60/90分)を設定すると、時間になると操作一覧に「☕ 休憩の時間です」と表示されます。操作一覧の右上には現在時刻も常に出ています。

画面のすぐ上(上端の少し上のあたり)にレーザーを当てると、5つのボタンが現れます。平面/湾曲はその画面だけの曲がりを切り替え、ミュートはその画面の音を消し、固定はその画面をその場に留めます(固定中はつかめなくなり、Yボタンの呼び直しでも動きません)。追従をONにすると画面が小さくなって視界の隅に付いてきます(チャットや監視の流し見に。もう一度で解除して元の大きさに)。明るさは100%→70%→40%と切り替わり、夜のまぶしさを抑えられます。

この表は標準設定です。ボタンごとの機能は、見る側ページの「⚙ 設定 → 操作」で変えられます(セクション7)。VRの中の操作一覧には、いまの割り当てが表示されます。

4. VRからパソコンを操作する(操作モード)

ブラウザには、ウェブページがパソコンのマウスを動かすことを禁止する決まりがあります。見るだけならページだけで足りますが、VRから操作するには、この禁止の外側で動く小さなプログラムがパソコン側に必要です。それが操作ヘルパーです。インストールは不要で、使うときに起動しておくだけです。起動していないあいだは、いままで通り「見るだけ」で使えます。

ヘルパーが動き出すと、パソコン側のページの「操作モード」の欄がおよそ3秒以内に自動でONに変わります。やめるときはヘルパーのウィンドウを閉じるだけ、いらなくなったらファイルをゴミ箱に入れるだけです。

ヘルパーは更新されることがあります(キー送信は版g、Bluetoothキーボード直送は版mから。中クリックは版2、横スクロールは版3から)。アプリを更新したら、ヘルパーも公開ページから再ダウンロードして差し替えるのが確実です(相対移動は版vのヘルパーから対応)。古いヘルパーのままでもマウス操作は動きますが、新しいキー機能や相対移動が効きません。

Windowsでの起動

  1. helper-windows.bat をダブルクリックする(公開したページの「操作モード」の欄からもダウンロードできます)
  2. 青い画面で「WindowsによってPCが保護されました」と出たら、「詳細情報」を押してから「実行」を押す。自分で用意したファイルなので実行して問題ありません
  3. 黒いウィンドウが開いて「waiting for your screen-share page」と表示されたら準備完了。VRを使い終わるまで開いたままにする
ダウンロード時にChromeが「このファイルは危険な可能性があります」と警告することがあります。ダウンロード一覧からそのファイルを選び、「保存」(または「継続」)を選んでください。

Macでの起動

  1. Launchpadで「ターミナル」を検索して開く
  2. ターミナルに半角で python3 と入力する(最後に半角スペースを1つ入れる)
  3. Finderから helper-mac.py をターミナルの画面へドラッグして、Enterキーを押す
  4. 「画面共有ページからの接続を待っています」と表示されたら準備完了。VRを使い終わるまで開いたままにする

初回だけ、次の2つが起きることがあります。どちらも1回きりです。

  • 「コマンドライン デベロッパツール」のインストールを求められたら、「インストール」を押して待つ(無料です。10分ほどかかることがあります)。終わったら手順をやり直す
  • マウス操作の許可を求められたら許可する。表示が出ないままマウスが動かないときは、システム設定の「プライバシーとセキュリティ」にある「アクセシビリティ」で「ターミナル」をオンにして、ヘルパーを起動し直す

5. 複数の画面と複数のパソコン

画面は横に増やせます。増やし方は2通りあって、組み合わせても使えます。増えた画面は、VRの中で横一列の弧に並びます。

同じパソコンの別のモニターを映す

  1. 共有中のパソコンの画面で「画面を追加(別のモニターを共有)」を押す
  2. 選択画面で、まだ映していないモニターを選んで「共有」を押す

追加した画面は一覧に「画面2」として並びます。やめたい画面は「はずす」で個別に消せます。

操作ヘルパーが動いていてモニターが2枚以上あると、各画面の横に「操作先: モニター1(メイン)」のような選択が出ます。これは「VRのこの画面をクリックしたら、実際のどのモニターでクリックするか」の対応付けです。ふつうは初期値のままで合いますが、クリックした場所と違うモニターでカーソルが動くときは、ここを合わせてください。ミラーリングした画面など、操作するつもりのない画面には「操作しない(見るだけ)」を選べます。

別のパソコンの画面も一緒に映す

  1. もう1台のパソコンでも同じURLを開き、「パソコン(共有する側)」から共有をはじめて、そのパソコンのコードを出す
  2. Questの接続後の画面で「別のパソコンを追加」を押し、そのコードを入力する

接続中のパソコンは一覧に並び、それぞれ「切断」できます。VRから操作したいパソコンでは、それぞれのパソコンで操作ヘルパーを起動しておきます。WindowsとMacの混在もかまいません。

スマホやタブレットの画面をVRに映す

ブラウザの決まりで、スマホやタブレットが自分の画面を配信することはできません(Android・iPhoneとも)。かわりに、いったんパソコンの画面にミラーリングして、そのウィンドウを「画面を追加」で共有します。縦長の画面は、VRの中でモニターと同じ高さの縦長パネルとして横に並びます。

  • iPhone / iPad + Mac: USBケーブルでつなぎ、QuickTime Playerで「ファイル → 新規ムービー収録」を開きます。録画ボタンの横の「⌄」を押して、入力に iPhone を選ぶと、Macの画面にスマホの画面が映ります。あとはVR Desktopの「画面を追加」を押し、選択画面の「ウィンドウ」からQuickTimeを選ぶだけです。
  • Android + Windows: Windows標準の「スマホ連携」アプリでスマホをつなぎ、スマホの画面をパソコンに表示します(画面の表示まで対応するのはSamsungなど一部の機種です)。対応していない機種では、Windowsのオプション機能「ワイヤレス ディスプレイ」を追加して、スマホの「キャスト」からこのパソコンに映す方法があります。映ったら、同じく「画面を追加」→「ウィンドウ」で選びます。
ミラーリングした画面は「見る専用」です。その画面の「操作先」を「操作しない(見るだけ)」にしておくと、レーザーを当ててもパソコンのカーソルが動かず安心です。

VRの中では

  • レーザーを当てている画面が操作の対象です。画面をまたぐと、カーソルもそのパソコンに切り替わります
  • グリップでつかんだ画面は弧の並びから独立して、好きな場所・高さに置けます。左手スティックの調整(遠近・大きさ)は、レーザーで指している画面だけに効きます
  • 並べ直したくなったら左手のYボタンで、全部をいまの正面の弧に呼び直せます(「固定」した画面はその場に残ります)
  • 各画面の「平面/湾曲・ミュート・固定・追従・明るさ」は、画面のすぐ上にレーザーを当てると現れるボタンで切り替えます
画面の枚数が増えるほど、映像の処理は重くなります。目安として2枚までは快適に動きます。3枚以上でカクつくときは、枚数を減らすか、パソコンとQuestを同じWi-Fiにつないでください。

6. スマホやタブレットで見る・操作する

スマホとタブレットは「見る側」として使えます。手順はQuestと同じです。同じURLを開いて「Quest・スマホ・タブレット(見る側)」を選び、6桁のコードを入れて、接続後に「タッチで見る」を押します。画面の共有はパソコン専用です。スマホのブラウザには、画面を配信するしくみそのものがないためです(逆に、スマホの画面のほうをVRに映したいときは、パソコン経由で映せます。セクション5へ)。

タッチでの操作は次の通りです。実際にパソコンを動かすには、パソコン側で操作ヘルパーが起動している必要があります(セクション4)。起動していないあいだは「見るだけ」になり、画面下にその表示が出ます。

スマホ / タブレット(「そのまま」の方式)はたらき
1本指でなぞるカーソル移動(触れている間、指を追いかけます)
タップクリック(2回続けてダブルクリック)
長押ししてから動かすドラッグ(範囲選択・つまみ)
すばやく2回タッチし、2回目を押したまま動かすドラッグ(長押しより速い。開始時に波紋の合図)
3本指で同時にタップ中クリック(ヘルパー版2から)
2本指で左右に動かす(等倍のとき)横スクロール(ヘルパー版3から)
2本指で上下スクロール
2本指でタップ右クリック
ピンチ手元でズーム(ズーム中は2本指で表示を移動)
パソコンのマウスはたらき
動かす画面の上にあるだけでカーソルが追従(押さなくてOK・「そのまま」の方式)
左クリック / 押したまま動かすクリック / ドラッグ
右クリック右クリック(ブラウザのメニューは出ません)
ホイールスクロール

「⚙ 設定 → 環境」の「カーソルの移動方法」、または画面上部の切替ボタン(「そのまま」/「なぞる」)で、なぞって動かす(トラックパッド式)に切り替えられます。ボタンにはいまの方式が表示されます。トラックパッドのように、動かしたぶんだけカーソルが進む方式です: タップ=クリック、長押ししてから動かす=ドラッグ(すばやく2回タッチして2回目を押したまま動かしてもドラッグできます。開始時に波紋が出ます)、マウスは押しながら動かすと移動(短く押すとクリック)します。ズーム中は移動量が自動で細かくなるので、狭いボタンを狙うときに便利です。相対移動には版v以降のヘルパーが必要です(そのままの方式は古いヘルパーでも全部動きます)。

ズーム中は右下に「等倍に戻す」ボタンが出ます。画面が複数あるときは、上部のタブで切り替えます。「全画面」でブラウザの枠を消せて、「設定」からは画質などをその場で変えられます。文字が小さくて読みにくいときは、ピンチでズームするのがいちばん手軽です。

パソコンのブラウザで「タッチで見る」を開くと、マウスがそのまま使えます。動かすだけでPCのカーソルが追従し、左クリック・右クリック・ホイールスクロールが効きます。トラックパッドの横スワイプやShift+ホイールで横スクロール(ヘルパー版3から)、ノートPCのトラックパッドなら、ピンチで相手のパソコンを拡大縮小できます(Ctrl/Cmd+『+』『-』のズームと同じ働き。ブラウザや多くのアプリで効きます)。スクロールの向きが逆に感じるときは「⚙ 設定 → 環境 → スクロールの向き」で合わせてください(この設定は端末ごとに保存されます)。もう1台のPCの画面をウィンドウで覗く「サブモニター的な使い方」に便利です。

カーソルの動かし方は「⚙ 設定 → 環境」の「カーソルの移動方法」で選べます。そのままは触れた場所・マウスの位置にカーソルが飛ぶ方式(初期設定)。なぞって動かすはトラックパッド式で、指を滑らせたぶん・マウスを(押しながら)動かしたぶんだけカーソルが相対的に動きます。なぞって方式では、タップ=いまの位置でクリック、長押ししてから動かす=ドラッグ、マウスは「押してすぐ動かす=移動、長押ししてから動かす=ドラッグ、短くクリック=クリック」です。2本指の上下スクロール・2本指タップの右クリック・ピンチズームは、どちらの方式でも共通です(ズーム中の2本指は表示の移動になります)。

上部の「⌨」を押すと、文字入力欄と主要キー(Enter・⌫・Esc・Tab・コピー/貼り付け・ウィンドウ切替)が現れます。入力欄に打った文字は「送信」でそのままパソコンに入力され、日本語も使えます(内部でクリップボードを使い、貼り付けの後に元の文字内容を戻します。コピーしてあったのが画像などの場合は戻せません)。こちらも新しいヘルパーが必要です。

7. 設定(画質・操作・環境)

設定は「⚙」ボタンから開きます。ページ右上の⚙は、パソコン(共有する側)の画面では画質だけ、見る側の画面では操作・画質・環境の全部を開きます。役割を選ぶ前のホーム画面には出ません。共有中の画面の下の「⚙ 画質の設定」、見る側の接続後の「⚙ 設定」、タッチ画面上部の「設定」からも開けます。VRに対応していない機器(スマホやタブレットなど)では、VRでしか使わない項目(ボタンの割り当て・背景・最大距離/幅)は最初から表示されません。内容はその端末のブラウザの中だけに保存され、外部には送られません(端末ごとに別々です)。

VRの中からも変えられます。標準では左手のXボタンで設定メニューが目の前に開き、レーザーとトリガーで、画質・背景・画面の最大距離と最大の幅・接続品質の表示・音量をその場で切り替えられます(開くボタンは「操作」タブで変更できます)。

画質

4つのプリセットから選びます。くっきりは文字を最優先(資料や文章の作業向き)、バランスは標準、なめらかは動きを最優先(動画やゲーム画面向き)、自動は通信状態にあわせてブラウザにおまかせです。映像はどのプリセットでも60fpsで取り込まれます。見る側で変えると、共有中のすべてのパソコンにすぐ反映されます。文字がにじむときは「くっきり」にした上で、パソコンと見る側を同じWi-Fi(できれば5GHz)につなぐのが効きます。VRの「画面の描画方式」は標準の「くっきり合成」のままが推奨です(平面の画面を合成器が直接描くため文字が読みやすく、消費電力も下がります。対応機のみ・湾曲画面は当面従来)。表示がおかしいときだけ「従来」に切り替えてください。

操作(見る側のみ)

VRコントローラーの8つのボタン(左右のトリガー・グリップ・A/B/X/Y)ごとに、クリック・右クリック・画面をつかんで移動などの機能を選びます。同じ機能を複数のボタンに割り当ててもかまいませんし(例: 標準では左右のトリガーと右Aボタン(下)がクリック、両グリップがつかむ)、「割り当てない」で空きボタンにもできます。スティックの役割(画面の調整とスクロールの左右入れ替え)、スクロールの速さ、レーザーの手ぶれを抑える「ポインターの安定化」(既定ON。細かいボタンが狙いやすくなります)もここで変えられ、「標準に戻す」でいつでも初期設定に戻せます。「トリガーのドラッグ」では、長押し後の移動をスクロールにするか(標準)、押した瞬間から常にドラッグにするかを選べます。「Bluetoothキーボードをそのまま送る」をOFFにすると、キーボード直送を止められます。変更した割り当てはVRの中の操作一覧にもそのまま反映されます。設定メニューを開くボタンがわからなくなっても、VR開始直後に自動表示される操作一覧パネルをレーザーでクリックすれば開けます。

環境(見る側のみ)

VRの背景を6種類から選べます。ダーク(標準・地平線がほのかに光る夜の空間)、まっ黒、星空(天の川つき)、昼の空(太陽と雲)、夕焼け(沈む夕日)、そしてパススルーです。パススルーは現実の部屋に画面が浮かぶ表示で、手元のキーボードや飲み物が見えるのが利点です(対応している機器でだけ選べます)。背景はVRの中の設定メニューからその場で切り替えられます。パススルーと他の背景の行き来だけは、VRに入り直したときに反映されます。

「画面の最大距離」と「画面の最大の幅」は、スティックで動かせる範囲の上限そのものです(初期値は12mと16m)。もっと遠く・もっと大きくしたいときはここを広げてください。VRの中の設定メニューの「+」でもその場で広げられます。

「VRの描画解像度」は、Quest側で絵を描くときの細かさです。「高(推奨)」で文字の輪郭が締まり、「最高」はさらに鮮明になるかわりに電池の減りが早くなります(反映は次にVRへ入るとき)。「文字のちらつき低減」は、画面を遠ざけたときや湾曲画面の端で細い文字がチラチラ震えるのを抑える処理で、初期ONです。

品質表示の「受信Mbps」は画面が静止していると自然に下がります(変化のない映像はほとんど送られないため)。数字が小さくても、文字がくっきりしていれば正常です。本当の実力は、動画を再生したりウィンドウを動かしたときの数字で見てください。「経路」は映像の通り道です: 直接(同一ネット)が最良、直接はインターネット越しの直接通信、中継サーバー(遅)は無料の中継サーバー経由で、数Mbps程度に制限され画質が上がりません。

「カーソルの移動方法」は、タッチで見るでのカーソルの動かし方(そのまま / なぞって動かす)です。VRのレーザー操作には影響しません。

「接続品質を表示する」をONにすると、受信中の通信量(Mbps)・なめらかさ(fps)・解像度・往復時間(ms)が、見る側の一覧、タッチ画面の上部、VRの操作一覧に出ます。往復時間は信号が2台の間を一往復する時間で、同じWi-Fiなら数ms〜十数msが目安です。カクつきの原因が回線なのか画質設定なのかを切り分けたいときに使ってください。数値はこの端末の中で測っているだけで、どこにも送信されません。音量のスライダーは、見る側で鳴る音の大きさです。「低遅延モード」は受信側のため込みを最小化する設定で、初期はONです。電波が不安定でカクつくときはOFFにすると安定することがあります。

VRの設定メニューの下部には配置スロット(A/B/C)があります。「保存」でいまの画面の配置(位置・大きさ・湾曲・固定・追従・明るさ)を丸ごと記憶し、「呼出」でいつでも復元できます。「仕事用」「映画用」のような使い分けに便利です(同じ画面構成のときに正しく復元されます)。

VRでの画面の配置(遠さ・大きさ・高さ・湾曲)も自動で記憶され、次回も同じ配置で始まります。

8. 困ったときは

接続でつまずいたときは、まず「通信を自己テスト」ボタンを、共有する側のパソコンと見る側の両方で押してください(共有画面のコードの下と、見る側のコード入力欄の下にあります)。「自分の住所 0件」と出た端末が原因で、ほとんどはブラウザの許可・ファイアウォール・VPNのどれかです。

1回目の接続が失敗しやすい、「接続中…」が長い
初回の通信路づくりは、環境によって数秒〜数十秒かかることがあります。版 2026-08-03s からは途中で打ち切らず、1本の接続を最大90秒じっくり待ちます(「通信路を作っています… ◯秒」と経過が表示されます)。切って作り直すと経路探しが最初からやり直しになってしまうためです。本当に失敗(failed)したときだけ、1回だけ作り直します。90秒待っても毎回失敗する場合: ①QuestとPCを同じWi-Fi名(SSID)につなぐ ②ルーターのプライバシーセパレーター(AP隔離)をOFF ③パソコン側のVPNを一時的にオフ。
前はつながっていたのに、急につながらなくなった(ブラウザの許可切れ)
ブラウザがサイトに出した許可は、しばらく使わないと自動で取り消されたり、ブラウザの更新でリセットされたりします。画面の共有だけはできても、機器どうしの通信の許可が落ちていると「経路: checking」のまま進みません。共有する側のパソコンで、アドレス欄の左の鍵アイコン →「このサイトの権限をリセット」→ ページを再読み込み → もう一度共有を試してください(共有時の許可も出し直しになります)。版 2026-08-03u からは、共有を始めた時点でこの状態を自動で検知し、共有画面に警告と手順を表示します。あわせて確認: Macはシステム設定→プライバシーとセキュリティ→ローカルネットワークでブラウザをON、Windowsはネットワークを「プライベート」にしてファイアウォールでブラウザを許可、共通でVPNはオフ。
診断ログが「経路: checking」のまま失敗する(直接つながらない)
信号のやり取りは成功しているのに、直結の通信路づくりに時間がかかっている状態です。版 2026-08-03s からは途中で打ち切らず、「通信路を作っています… ◯秒」と表示しながら最大90秒そのまま待ちます。多くの環境では数秒〜数十秒で「経路: connected」に変わるので、切らずにお待ちください。90秒待っても毎回作れない場合はルーターを確認します: ①QuestとPCを同じWi-Fi名(SSID)につなぐ ②ルーター設定の「プライバシーセパレーター」「AP隔離」「ネットワーク分離」をOFFにする(メーカーにより名称が違います) ③PCのVPNを切る。
コードを入れても「見つかりません」と出る
パソコン側が共有中か、コードが合っているかを確認します。共有をやり直すたびにコードは新しくなります。パソコンとQuestの両方がインターネットにつながっている必要があります。
受信が数Mbpsしか出ない、動かすとにじむ
画面が静止しているときの受信1〜2Mbpsは正常です(上の説明を参照)。動かしても数Mbpsのままなら、まずWi-Fiの電波状態を疑ってください(ルーターに近づく、5GHzを選ぶ、PCを有線にする)。なお、このアプリの映像は必ず機器どうしの直結で流れる設定になっています。品質表示の「経路」に「中継サーバー(遅)」と出ることは本来なく、もし出た場合は設定どおりに動いていない異常なので、ページの再読み込みと、それでも直らなければ開発時の確認事項として控えておいてください。
映像がカクカクする、遅れる
パソコンとQuestを同じWi-Fiにつなぐと速くなります。ルーターの近くで使う、5GHzのWi-Fiを選ぶ、の2つも効きます。共有するパソコンを有線LANにつなぐのはさらに効果が大きいです。それでも波打つように乱れるときは、「⚙ 設定 → 環境」の低遅延モードをOFFにすると安定することがあります。
音が出ない
共有をはじめるときの選択画面で「音声を共有」にチェックが必要です。WindowsのChromeは「画面全体」でも音を共有できます。Macは画面全体の音を共有できないことが多く、その場合は音なしになります(Chromeの「タブ」共有ならそのタブの音だけ届きますが、操作モードとの相性は悪くなります)。
VRから操作できない
パソコン側のページで「操作モード」がONになっているかを見ます。OFFのままなら、操作ヘルパーが起動していません。ONなのに動かないときは、「ウィンドウ」や「タブ」ではなく「画面全体」を共有しているかを確認します。 操作モードがOFFのときは、パソコン画面の接続状態の下に「直近の失敗」という診断が表示されます。「遮断/拒否されています」と出たらブラウザのローカルネットワーク許可が切れています(ページを再読み込みして、出てきた確認で許可し直してください)。「応答していません」と出たらヘルパー側の問題です(ヘルパーの黒い画面を閉じて起動し直してください)。
クリックの位置がずれる
「ウィンドウ」や「タブ」ではなく「画面全体」を共有してください。ヘルパーは画面全体を基準にカーソルを動かすためです。モニターが複数あるパソコンでは、各画面の横に出る「操作先: モニター○」の選択を、実際に映しているモニターに合わせます(セクション5)。
画質が粗い、文字がにじむ・読みにくい
効く順に4つあります。①「⚙ 設定 → 環境」のVRの描画解像度を「高」か「最高」にする(次のVR開始から) ②画質を「くっきり」にする ③パソコン側の表示スケールを125〜150%に上げる(Windows: 設定→ディスプレイ→拡大縮小 / Mac: 設定→ディスプレイ→文字を拡大)。文字そのものが大きくなるのが一番確実です ④文字中心の画面は画面上のボタンで「平面」にする(湾曲は端がわずかににじみます)。あわせて、同じWi-Fi・画面枚数を減らす、も効きます。
クリックやドラッグのあとに操作が効かなくなる
「離す」信号が一瞬届かないと起きることがありました。今回の版から押しっぱなしを自動で検知して復帰します。それでも固まったように見えたら、ボタンをすべて離してから、何もない所を1回クリックしてください。
画面が最初から高い位置に出る
旧版にあった「全体の高さ」調整の記憶が残っていたのが原因です。今回から初期の高さは固定になりました。高さを変えたいときは、画面をグリップでつかんでそのまま上下に動かします。
キー送信パレット・⌨・Bluetoothキーボードがパソコンに届かない
パソコンで動かしている操作ヘルパーが古い版です。ヘルパーの版は、ヘルパーを起動したときの黒い画面に「ヘルパーの版」として表示されます。古い場合はパソコン画面の接続状態にも「ヘルパーが古い → 再ダウンロード推奨」と出ます。公開ページから新しい helper ファイルをダウンロードして差し替え、起動し直してください。Bluetoothキーボードは「⚙ 設定 → 操作」の「そのまま送る」がONかも確認を。日本語の変換入力はスマホの「⌨」入力欄を使ってください。
Wi-Fiが一瞬切れた、「再接続しています」と出た
切断から約2分間は、同じコードで自動的に再接続を試みます。コードの入れ直しは不要です。2分を過ぎると通常の切断扱いになるので、パソコン側の共有を確認してから、もう一度コードを入力してください。
Macだけ画質が悪い
MacのRetina画面は情報量がとても多く、圧縮が追いつかずにブラウザが自動で画質を落とすことがあります。今回の版から、VRで見分けられる上限(横2560)に取り込みを自動で整えるようにしました。あわせて「⚙ 設定」の画質を「くっきり」にすると文字がさらに安定します。
背景で「パススルー」が選べない
その機器のブラウザがパススルー表示に対応していません。Quest本体のブラウザで開いたときに選べます。
スマホやタブレットの画面をVRに映したい
スマホからの直接配信はブラウザの決まりでできません。パソコンにミラーリングして、そのウィンドウを「画面を追加」で共有します(セクション5)。
更新したはずの機能が出ない、動きが説明と違う
更新前のページがブラウザに残っている可能性があります。ページを再読み込みし、直らないときはタブを閉じて開き直してください。いま動いている版は、ホーム画面の下部と「⚙ 設定」の見出しの横に「版 日付」で表示されます。
会社のパソコンで動かない
管理者の設定でヘルパーの実行が止められている場合があります。その場合は見るだけで使ってください。

9. 通信のしくみと安全性

このアプリの中では、性質の違う3つの通信が動いています。順番に見ていきます。

1. 待ち合わせ(シグナリング)

パソコンとQuestは、最初にお互いの居場所を知る必要があります。6桁のコードは、そのための待ち合わせ番号です。パソコンは共有をはじめた瞬間に、この番号を名札としてPeerJSの公開サーバーに登録します。Questが同じ番号を入力すると、サーバーが両者に相手の接続情報を伝えます。

ここを通るのは、IPアドレスや利用できる映像形式といった接続の段取りの情報だけです。画面の中身は通りません。相手が見つかった時点で、このサーバーの役目は終わります。

2. 映像と音声

待ち合わせが済むと、パソコンとQuestは直接つながります。WebRTCという、ブラウザに最初から入っているビデオ通話用の規格を使っています。同じWi-Fiにいる場合、映像は家のネットワークの中だけを流れ、インターネットには出ていきません。これが遅れの少なさにつながります。

途中でSTUNサーバーという道案内役を使いますが、これは自分のアドレスを知るためのもので、映像は経由しません。映像と音声はDTLS-SRTPという方式で自動的に暗号化されます。

3. 操作の信号

VRからのマウス操作は、同じWebRTC接続に用意されたデータ用の通り道(データチャネル)で、Questからパソコンへ送られます。送っているのは「画面のどの位置か」を0から1の割合で表した座標と、クリックやスクロールの種類だけです。1秒あたり最大50回、まとめて送っています。

受け取ったパソコンのページは、それを 127.0.0.1:8765 という自分自身の中だけに開かれた受け口へ渡します。操作ヘルパーがそこで受け取り、画面の解像度に合わせて実際のカーソル位置に変換して動かします。この最後の区間は、パソコンの外に一切出ません。

安全性について

  • 公開したURLを誰かが開いても、そのときの6桁コードを知らなければ画面には接続できません。コードは共有をやり直すたびに変わります
  • 見る側は、1台のパソコンに同時に3台までつなげます(4台目がつながると一番古い接続が切れます)。Questで見ながらスマホを「⌨」専用のリモートキーボードにする、という合わせ技もできます。共有する側のパソコンも複数台つなげます(セクション5)
  • 操作ヘルパーは、同じパソコンの中からの通信しか受け付けません(外部のネットワークからは届きません)。さらに、最初につながった画面共有ページを覚え、それ以外のページからの指示は拒否します
  • ヘルパーが受け付けるのは、カーソル移動、クリック、スクロール、キー入力(文字の入力を含む)です。ファイルを読む、送るといった機能は持っていません
  • 共有中の画面をすべて「操作しない」にしたパソコンには、マウス操作だけでなくキー入力も送られません(1枚でも操作できる画面があれば、キー入力は通ります)
  • ヘルパーのウィンドウを閉じれば操作は止まり、パソコン側のページの表示も自動でOFFに戻ります
まれに、ネットワークの構成によっては直接つながれないことがあります(会社や学校の回線に多い構成です)。パソコンとQuestを同じWi-Fiにつなぐと、ほとんどの場合これを避けられます。
